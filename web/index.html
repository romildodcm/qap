Instalação — Flashear o RádioInstallation — Flashing the Radio

  1. Baixe o firmware na seção Releases (arquivo ...-firmware.packed.bin).
  2. Download the firmware from the Releases section (the ...-firmware.packed.bin file).
  3. Faça backup do firmware de fábrica antes de qualquer gravação.
  4. Back up the factory firmware before any flashing.
  5. Grave com o Web Flasher — egzumer.github.io/uvtools (Chrome/Edge via Web Serial).
  6. Flash with the Web Flasher — egzumer.github.io/uvtools (Chrome/Edge via Web Serial).
  7. Ligue e escute — o rádio inicia direto no scanner airband.
  8. Power on and listen — the radio boots straight into airband scanner mode.
